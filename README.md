# lab12

Данная лабораторная работа посвящена изучению текстового редактора Vim.

## Ход работы

1. Установила редактор Vim:

```bash
sudo apt install vim -y
```

2. Проверила версию Vim:

```bash
vim --version
```

Результат:

```bash
VIM - Vi IMproved 9.1
```

3. Запустила встроенный учебный материал Vim:

```bash
vimtutor ru
```

4. В процессе работы были изучены базовые команды Vim:

* перемещение по тексту;
* переход в режим вставки;
* удаление символов;
* сохранение файла;
* выход из редактора
